ทุกครั้งที่กดได้ 1 แถว (สวิตช์ได้ทั้งตอนกดลงและตอนปลด) · machine 0 = ทั้งไลน์ · สรุป OEE ในแท็บ OEE_Daily / OEE_Hourly อัปเดตทุก 15 นาที

M1–M4 door · ปุ่ม 6×6 (ขา 23, 19, 18, 17)

กด 1 ครั้ง = เปิดฝา door_open · กดอีกครั้ง = ปิดฝา door_close · ฝาบนหน้าเว็บเลื่อนตาม

OEE: ฝาเปิด = เครื่องหยุด → ลด Availability

GOOD · ปุ่ม 6×6 (ขา 16)

ตรวจแล้วดี → ย้าย 1 กล่องจาก กอง 1 (QC wait) ไป กองเขียว · good machine 0

OEE: Quality = good ÷ (good + reject)

REJECT · ปุ่ม 6×6 (ขา 4)

ตรวจแล้วเสีย → ย้าย 1 กล่องจาก กอง 1 ไป กองแดง · reject machine 0

OEE: ลด Quality

ชิ้นงาน · บอร์ดผลิตเอง

เครื่องที่เดินอยู่ทำเสร็จ 1 ชิ้นทุก cycle (M1 18 s · M2 30 s · M3 24 s · M4 36 s ที่ 100 %) แล้วส่งต่อเครื่องถัดไป → part · ชิ้นจาก M4 ลง กอง 1

OEE: นับชิ้น → Performance

M1–M4 run · สวิตช์ 7×7

กดติด = เครื่องเดิน run_on · ปลด = หยุด run_off

OEE: เวลาเดิน → Availability (นับว่าเดินเมื่อ run ติด + ไม่มี alarm + ฝาปิด + ความเร็ว > 0 %)

ALARM · สวิตช์ 7×7

E-stop ทั้งไลน์ alarm_on / alarm_off machine 0 · ไฟ LED บนบอร์ด (GPIO 2) ติด

OEE: ทุกเครื่องหยุด เวลานี้นับเป็น stop + alarm → ลด Availability

M1–M4 speed · pot

ความเร็ว 0–200 % (ทีละ 5 %) · ไม่สร้างแถว Events — ส่งไปใน speed_pct ของสรุปรายนาที

OEE: หมุนไป 0 % = เครื่องหยุด → ลด Availability

EN · ปุ่มบนตัวบอร์ด

รีสตาร์ตบอร์ด → boot machine 0 (ตัวนับ part / good / reject บนบอร์ดเริ่มใหม่ แต่ใน database ไม่หาย)

ไม่ใช่ปุ่มทดสอบ · BOOT ใช้ตอนอัปโหลดโค้ดเท่านั้น

ทุกสวิตช์: GPIO ↔ สวิตช์ ↔ GND ไม่ต้องใช้ตัวต้านทาน pot ใช้ 3.3V เท่านั้น ห้าม 5V ขากากบาทแดง = ห้ามต่อ
GND 3.3V pot → speed run switch alarm door (ฝาเครื่อง) QC good QC reject

ชี้ที่สายหรือแถวในตารางเพื่อดูทีละเส้น · ลำดับขาในรูปคือบอร์ด 38 ขาแบบทั่วไป ให้เทียบชื่อที่พิมพ์ข้างขาบนบอร์ดจริงทุกครั้งก่อนเสียบ

เช็กลิสต์เสียบสาย

เสร็จขา ESP32ต่อกับหน้าที่ส่งเข้า Eventsมีผลกับ OEEอีกขาของอุปกรณ์

สวิตช์ 7×7: ใช้แถวเดียวจาก 2 แถว · ขากลางลง GND · ขาริมเข้า GPIO · ถ้าล็อกแล้วหน้าเว็บขึ้น STOP ให้ย้ายสายไปขาริมอีกข้าง
ปุ่ม 6×6: เสียบคร่อมร่องกลาง breadboard แล้วใช้ขาทแยงมุมกัน
ไม่ได้ต่อ pot: แก้ HAVE_POTS = false ในโค้ด · ไฟ Alarm: ใช้ LED บนบอร์ด (GPIO 2) ไม่ต้องต่อ
ทดสอบ: เปิด run ทุกเครื่อง รอให้มีกล่องในกอง 1 แล้วกด GOOD → กล่องย้ายไปกองเขียว และภายใน ~10–20 วินาที แท็บ Events ใน Google Sheet มีแถว whole line · good · กดปุ่ม M1 → ฝาเครื่อง 1 เปิด (door_open) · ไม่ขึ้น: ดู docker compose logs -f sheets-sync
